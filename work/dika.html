Dika

An idea for helping a team get work done with coding agents. Not built yet.

Exploring with coding agents
Not built yet · 2026

The problem. Writing code is only part of the job. People still have to pass on context, chase reviews, and check that the change works.

Today. I’ve explored the idea with coding agents through research, design, and a demo. There is some starter code, but the product isn’t built yet.

What I want. A team can say what it needs, let agents do more of the work, and step in when a decision needs a person. Less passing work back and forth.

Sources & limits

Checked against the private design, demo, and application records. Dika is a direction I want to pursue, not a tool a team is using yet.
