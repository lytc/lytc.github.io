work-orchestrator

In use: my tool for keeping track of agents, tasks, and follow-ups.

Built with coding agents
In personal use · 2026

Why I built it. Work gets scattered across chats, tasks, and pull requests. I don’t want to keep it all in my head.

Today. I use it to see what needs attention, pick up unfinished work, and follow up on reviews and checks. It helps me manage several agents without constantly rebuilding the context.

What I want. Less chasing updates. More time solving the actual problem.

Sources & limits

Checked against private code and work records. The benefits describe my own experience; time savings have not been measured.
