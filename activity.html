Dates, monthly rates, and limits

Calendar-year grouping in UTC. Opened PRs use creation date; merged PRs use merge date. Period PR counts were checked through REST and GraphQL search. Review counts use actual submitted review timestamps, paginating all matching PRs and review connections, with self-authored PRs and pending drafts excluded. The same PR can be reviewed in more than one period. Product commits and TypeScript diffs use Git author dates in the snapshots defined below.

Before 2024 means calendar years 2011–2023 (156 months). Full years use 12 months. The incomplete 2026 period uses elapsed time since January 1 at collection, divided by an average month of 365.25/12 days. The displayed rate is rounded to one decimal place.

Calculation and limits

Count distinct PRs with at least one submitted review by my account, excluding self-authored PRs. The 1,024 search candidates included eight PRs with draft-only reviews; these are excluded, leaving 1,016 PRs with submitted reviews.

Opened and merged PRs overlap. The review figure counts distinct PRs with submitted reviews, not review events or comments. It excludes pending drafts. Counts reflect visible records at collection, include AI-assisted work, and do not measure quality. Private source records are not published.

Calculation and limits

Enumerate commits reachable from each pinned snapshot, exclude merges, and match author names exactly. Cross-check git log against git rev-list; combine commit SHA sets across repositories.

A count of commit objects in the selected history, not distinct features, production releases, or all career work. Imported history, cherry-picks, and rebases can represent similar work under different SHAs. Squashed work may appear as one commit. No ranking of colleagues or productivity inference.

The local snapshots were not refreshed during this measurement.

Filtering and verification

Sum Git numstat with rename detection for .ts, .tsx, .mts and .cts files in the selected non-merge commits. Cross-check git log against a separate git diff-tree calculation using NUL-delimited paths. Exclude declaration files, known generated GraphQL bindings/introspection, shared generated types, dependency and build folders, fixtures, examples, migration files, and the country-code dataset.

Diff line changes, not current source LOC or unique lines written by hand. Blank and comment lines count. Repeated edits, formatting, copied/imported work, and AI-assisted implementation can remain. Filtering is not a complete authorship audit. Added minus deleted is not personal ownership of the current codebase. No claim of a productivity or quality score.
